# Работа над CRM AllPlugs

Сергей обсуждает улучшения в чате. Перед изменением интерфейса покажи макет и дождись согласования. Используй русский язык для интерфейса, пояснений и сообщений коммитов.

Вноси согласованные изменения непосредственно в эту рабочую копию. Проверь git status до работы, сохрани чужие изменения, проверь сборку командой npm run build и подходящие пользовательские сценарии. Сам создавай локальные коммиты только с файлами задачи. Сообщай результат проверки и короткий хеш.

По просьбе Сергея опубликовать изменения проверь удалённый репозиторий, ветку и реальные настройки деплоя Timeweb. После отправки проверь рабочую версию. Контекст приложения и интеграций описан в CLAUDE.md.
